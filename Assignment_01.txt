1.	What is a List?
List is a collection of elements. It is ordered,	mutable, and heterogenous. It allows duplicate entries. Indexing and slicing is possible. All the elements in a list are enclosed within [ ] and separated by a comma. 

2.	What is a Tuple?
It is a collection of elements. It is ordered, and Immutable and heterogenous. It allows duplicate entries. Indexing and slicing is possible. All the elements in a tuple are enclosed within ( ) and separated by a comma.

26.	How to flatten a list in Python?
lst = [1, 2, [3, 4], 5, [6, 7, 8]]
flat_lst = []
for i in lst:
    if isinstance(i, list):
        for j in i:
            flat_lst.append(j)
    else:
        flat_lst.append(i)
print("Flattened list:", flat_lst)

27.	How to sort a list in ascending and descending order without using the sort function?

# Ascending order
for i in range(len(lst)):
    print(i)
    for j in range(i + 1, len(lst)):
        if lst[i] > lst[j]:
            lst[i], lst[j] = lst[j], lst[i]

# Descending order
lst = lst.copy()

for i in range(len(lst)):
    for j in range(i + 1, len(lst)):
        if lst[i] < lst[j]:
            lst[i], lst[j] = lst[j], lst[i]
	print(lst)

35.	What is the difference between copy and deep copy?
